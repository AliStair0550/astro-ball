# Skrifter

Begge familier er navngivet i designdokumentets afsnit 8 og er udgivet
under SIL Open Font License 1.1, som tillader, at de ligger med i
projektet.

| Fil | Brug |
|---|---|
| `Unbounded-900.ttf` | ASTRO BALL som brandlogo, kombo-tallet |
| `Unbounded-700.ttf` | Level clear og store tal |
| `SpaceGrotesk-700.ttf` | Score, tabulær |
| `SpaceGrotesk-500.ttf` | Level-linje, power-up-dock, debug |

Licenserne ligger i `OFL-Unbounded.txt` og `OFL-SpaceGrotesk.txt`.
